# Greenden Clone – Tailwind CSS Practice Project

## About the Project

This project is a responsive **Greenden-inspired website** created as part of my Tailwind CSS practice. The main goal of this project was to improve my understanding of **utility-first CSS** and build a clean, responsive user interface using Tailwind CSS.

I developed the project by practicing and applying various Tailwind CSS concepts such as layout, spacing, flexbox, grid, responsive design, colors, hover effects, and reusable utility classes.

## Features

* Responsive and user-friendly design
* Built using Tailwind CSS
* Clean and modern user interface
* Responsive navigation bar
* Product and service sections
* Flexbox and Grid layouts
* Hover and transition effects
* Mobile-friendly responsive design

## Technologies Used

* HTML5
* Tailwind CSS

## Project Purpose

This is a **practice project** created to strengthen my Tailwind CSS skills. I used the Greenden website design as a reference and recreated the layout independently for learning and practice purposes.
